# Contributing to Credit Scoring for Unbanked Retailers

First off, thank you for considering contributing to this project! It’s people like you that make this a great tool for financial inclusion in Nigeria.

## How Can I Contribute?

### 1. Reporting Bugs
- Check the [Issues Tab](https://github.com/Racheal253/credit-scoring-unbanked-retailers/issues) to see if the bug has already been reported.
- If not, open a new issue. Clearly describe the problem, including steps to reproduce the error and your expected outcome.

### 2. Suggesting Enhancements
- We are always looking for better alternative data features!
- If you have an idea (e.g., "We should include electricity bill payment patterns"), open an issue with the tag `enhancement`.

### 3. Pull Requests (Code Changes)
1. **Fork the repo** and create your branch from `main`.
2. **Local Setup**: Ensure you have PySpark and the dependencies in `requirements.txt` installed.
3. **Coding Standards**: 
   - Use clear variable names (e.g., `avg_monthly_transactions` instead of `amt`).
   - Add comments to your PySpark logic so others can follow your thought process.
4. **Testing**: Run your notebook/script to ensure no errors are introduced.
5. **Submit**: Open a Pull Request with a clear description of what you changed.

## Data Privacy Note
Since we use **synthetic data** for this project, please **do not** upload any real-world retailer data or PII (Personally Identifiable Information) to this repository.

## Our Style Guide
- **Python**: Follow PEP 8 where possible.
- **Notebooks**: Clear all outputs before committing to keep the file size small.
- **Commit Messages**: Use the present tense ("Add feature" instead of "Added feature").
